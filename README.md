IT Support & Automation Lab

Hands-on IT support lab focused on automation, troubleshooting, system administration, and technical documentation across Windows and Linux environments.

Project Overview

Automation Scripting: PowerShell and Bash scripts for automating common administrative and system maintenance tasks.
System Administration: User management, permissions, services, system health monitoring and basic Windows OR Linux administration.
Troubleshooting SOPs: Step-by-step documentation for diagnosing and resolving common network, system, and connectivity issues.
Home Lab: A virtualized Windows and Linux environment used to test scripts, simulate issues, and practice troubleshooting.
